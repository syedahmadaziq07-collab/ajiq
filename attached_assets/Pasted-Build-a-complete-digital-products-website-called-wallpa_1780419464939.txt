Build a complete digital products website called "wallpaper.minimalist" using Next.js 14 with App Router, Tailwind CSS, and TypeScript. The design must be pixel-perfect inspired by askalm.com — clean, flat, minimalist. NO shadows, NO gradients anywhere.

=== BRAND INFO ===
Brand name: wallpaper.minimalist
Tagline: Refining digital life.
Description: We craft simple essentials that make every workspace inspiring and every device more productive.
Support email: support@wallpaper.minimalist
Products: Wallpapers, Guides, Templates

=== TECH STACK ===
- Next.js 14 App Router (not pages router)
- TypeScript
- Tailwind CSS
- Google Fonts: Inter (load via next/font/google)
- No external UI libraries (no shadcn, no chakra, no MUI)

=== IMPORTANT TECHNICAL REQUIREMENTS ===

1. next.config.js — add Unsplash to allowed image domains:
/** @type {import('next').NextConfig} */
const nextConfig = {
  images: {
    domains: ['images.unsplash.com'],
  },
}
module.exports = nextConfig

2. Use next/image for ALL images with proper width and height props. Never use <img> tag.

3. Load Inter font in app/layout.tsx:
import { Inter } from 'next/font/google'
const inter = Inter({ subsets: ['latin'] })

4. tailwind.config.ts — extend with custom colors:
colors: {
  brand: {
    black: '#000000',
    white: '#FFFFFF',
    gray: '#747474',
    border: '#EEEEEE',
    blue: '#0000EE',
  }
}

5. Global CSS (app/globals.css):
- Remove all default margins/paddings
- Set body font to Inter
- Add smooth scroll: html { scroll-behavior: smooth; }
- Add transition for all interactive elements

6. Each page must have unique metadata:
export const metadata = {
  title: '[Page] | wallpaper.minimalist',
  description: '[unique description]',
}

7. Navbar active state: use usePathname() from next/navigation to highlight current page link

8. All hover effects:
- Cards: transform scale(1.01) transition-all duration-200
- Links: underline slides in (use underline-offset-2)
- Buttons: bg changes on hover

9. Responsive breakpoints:
- Mobile < 640px: single column, px-4, reduced font sizes
- Tablet 640-1024px: 2 columns, px-6
- Desktop ≥ 1024px: full layout, max-w-[1200px] mx-auto

10. NO dark mode — light mode only. Add suppressHydrationWarning to <html> tag.

Build ALL pages and components completely. Do not use placeholder comments like "// add content here". Every component must be fully implemented with real content. Start with layout.tsx, then Navbar.tsx, Footer.tsx, then home page, then all other pages.
